PHISHING AWARENESS GUIDE

Introduction

Phishing is a cybersecurity threat in which criminals use fraudulent messages to trick individuals into revealing confidential information such as passwords, banking details and personal information. This project provides a basic educational resource to help users understand, identify and prevent phishing attacks.

Project Objectives

The main objectives are:

- To explain the meaning of phishing.

- To identify common phishing techniques.

- To recognize warning signs of phishing messages.

- To explain how phishing attacks can be prevented.

- To educate users on reporting suspicious messages.

Project Scope

This project focuses on phishing awareness among students, employees and ordinary internet users. It covers email phishing, SMS phishing and fraudulent online messages.

Project Contents

The repository contains the following resources:

- introduction-to-phishing.md

- recognising-phishing.md

- preventing-phishing.md

- references.md

Importance of Phishing Awareness

Phishing awareness is important because cybercriminals often use deceptive messages to obtain confidential information or gain unauthorized access to accounts.

Users should learn to recognize suspicious messages, verify unexpected requests and report possible attacks (CISA, 2024a).

Conclusion

Phishing remains an important cybersecurity concern.

Understanding how phishing attacks operate and

following appropriate security practices can reduce

the risk of becoming a victim.
