PREVENTING PHISHING ATTACKS

Introduction

Preventing phishing attacks involves using appropriate security practices and being careful when receiving unexpected online communication. Both individuals and organisations have a role to play in reducing phishing risks.

Password Security

Users should create strong and unique passwords for their online accounts. Passwords should not be shared with other people. A password manager can also help users manage

different passwords securely.

Multi-Factor Authentication

Multi-factor authentication (MFA) provides an additional layer of account protection. It requires users to provide another verification method in addition to their password. This can make unauthorised access more difficult even when a password has been compromised (CISA, 2024b).

Avoid Suspicious Links

Users should avoid clicking links in unexpected emails and text messages. If a message appears to come from a legitimate organisation, users should visit its official website independently rather than using an unverified link.

Keep Devices Updated

Operating systems, applications and security software should be updated regularly. Updates may contain security improvements that help protect devices against known threats (FTC, n.d.).

Reporting Phishing Attacks

When users receive suspicious messages, they should:

1. Avoid clicking links or opening attachments.

2. Report the message using the available reporting function or to the relevant

organisation's security team.

3. Delete the suspicious message after reporting.

4. Inform the relevant IT department if the incident involves an organisational account.

CISA recommends recognising, reporting and deleting suspected phishing messages

(CISA, 2024a).

What to Do After Becoming a Victim

If a user has entered their password into a fraudulent website, they should:

- Change the affected password immediately.

- Change reused passwords on other accounts.

- Contact the relevant organisation or bank if financial information is exposed.

- Enable multi-factor authentication.

- Report the incident to the relevant authority.

3. 8 Conclusion

Phishing prevention requires awareness, caution, and appropriate security measures. Users who follow good cybersecurity practices can reduce the likelihood of becoming victims of phishing attacks.
